# Screenshots

The README embeds these images. They are generated by `scripts/screenshots.py` (Playwright,
headless Chromium; a dev-only dependency) from a demo instance, signed in as `riskmanager` at
1440×900:

```sh
make run                                   # in one terminal (after import_attack + seed_demo)
SCREENSHOT_PASSWORD=<riskmanager password> make screenshots
```

The script fails if any page logs a browser console error or a CSP violation, so it also works as
an end-to-end check of the UI under the strict Content Security Policy.
